Difference between Import and Insert in Rhino

When you want to bring in a file into your current Rhino file, you have two options: import and insert. Importing a file will bring in the geometry but not the layers, materials, or any other information. Inserting a file will bring in everything including the layers, materials, and any other information. So if you want to keep the layers and materials of the file you're bringing in, you should use insert. If you just want the geometry and don't care about the layers or materials, you can use import.
