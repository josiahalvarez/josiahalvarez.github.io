November 20th, 2026 - Commands of the Week

Rhino

  • NamedPosition - Saves a snapshot of the position of objects (think exploded views without having to make a duplicate of the geometry)

Grasshopper

  • Ctrl + Shift - Drag from one output to another
  • Ctrl + Alt + Click - Find where a component lives in the ribbon
  • Double click + "0<5<10" - Create a range of values

Blender

  • Render -> Light Paths -> Fast Glboal Illumination
  • Render -> Light Paths -> Fast Glboal Illumination -> # of Bounces (2 is fairly dark and 12 is up there)
  • Render -> Light Paths -> Fast Glboal Illumination -> AO Distance (1000cm is typ.)
  • Max Samples = 16 (for Viewport)
  • Object -> Relations -> Pass Index (0)
