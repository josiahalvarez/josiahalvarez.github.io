Shortcuts

how to make your mouse and keyboard an extension of your body

When a tool is used for hundreds or even thousands of hours, at some point it almost becomes an extension of yourself. Whether that be the pencil for the draftsman, the brush for the painter, or the glove to the baseball player, that's what we're striving for when we open up the computer. This includes navigating in general and using architectural/design software. Below is a list of some of the shortcuts that will give you a pretty good start.

Windows (for mac users replace ctrl with command and alt with option)

  • Alt + Tab - holding alt and pressing tab allows you to see and switch between different windows
  • Ctrl + Backspace - while typing anything on your computer use this to delete a whole word rather than a single character
  • Windows + Tab - pressing these together will allow you to see all your windows and click on the one you want
  • Ctrl + Alt + Delete - Task Manager. Right click on a program to force quit
  • Alt + Shift - cycles through the language options

File explorer (most of these apply to pretty much everything so try them out)

  • Windows + E - opens up file explorer
  • F2 - rename selected item
  • Ctrl - holding ctrl in most programs will allow you to select multiple items at a time
  • Shift - selecting an item (like in the file explorer) and clicking on an item much above or below will select everything in between.
  • Ctrl + A - selects everything
  • Ctrl + X - cuts selected item(s)
  • Ctrl + V - pastes copied item(s)
  • Ctrl + C - copies selected item(s)
  • Ctrl + Z - undo
  • Ctrl + Y - redo
  • Ctrl + Shift + N - creates new folder
  • Alt + Enter - opens up properties of the selected item

Browser

  • Ctrl + T - opens new tab
  • Ctrl + W - closes tab
  • Ctrl + Shift + T - reopens last closed tab
  • Ctrl + (1-9) - to select the tab corresponding to the number
  • Ctrl + R - refreshes page
  • Ctrl + F - search within the page
  • Ctrl + Tab - switches to next tab
  • Ctrl + Shift + Tab - switches to previous tab
  • Ctrl + L - focuses the address bar
  • Ctrl + D - bookmarks current page
  • Ctrl + J - opens downloads page
