Programs

Most architecture software and learning is catered to Windows unfortunately despite growing support for Macs... I pretty much use all of these programs everyday.

  • Everything is a search tool that actually works
  • ShareX is a customizable screenshot and recording tool that comes with more features than you would ever need
  • Toggl Track allows you to track your time and see trends over time (has mobile integration)
  • WizTree visualizes the storage on your computer so you can clean it up
  • Notepad ++ is a better notepad app
  • 7zip is a better way to extract on Windows
