Shortcuts

how to make your mouse and keyboard an extension of your body

When a tool is used for hundreds or even thousands of hours, at some point it almost becomes an extension of yourself. Whether that be the pencil for the draftsman, the brush for the painter, or the glove to the baseball player, that's what we're striving for when we open up the computer. This includes navigating in general and using architectural/design software. Below is a list of some of the shortcuts that will give you a pretty good start to achieving that status.

Windows (for mac users replace ctrl with command and alt with option)

  • Alt + Tab - holding alt and pressing tab allows you to see and switch between different windows
  • Windows + Tab - pressing these together will allow you to see all your windows in a readable format and click on the one you want
  • Windows + D - minimizes all windows and shows the desktop
  • Ctrl + Shift + Esc OR Ctrl + Alt + Delete (I like this one better) - Task Manager. Right clicking on a program allows you to force quit it if necessary

File explorer

Most of these apply to other programs as well so try them out.
  • Windows + E - opens up the file explorer
  • F2 - rename selected item
  • Ctrl - holding ctrl in most programs will allow you to select multiple items at a time
  • Shift - selecting an item (like in the file explorer) and clicking on an item much above or below will select everything in between.
  • Ctrl + A - selects everything
  • Ctrl + X - cuts selected item(s)
  • Ctrl + V - pastes copied item(s)
  • Ctrl + C - copies selected item(s)
  • Ctrl + Z - undo
  • Ctrl + Y - redo
  • Ctrl + Shift + N - creates a new folder
  • Alt + Enter - opens up the properties of the selected item

Browser

  • Ctrl + (1-9) - to select the tab corresponding to the number
  • Ctrl + T - opens a new tab
  • Ctrl + W - closes the current tab
  • Ctrl + Shift + T - reopens the last closed tab
  • Ctrl + F - opens the find bar to search within the current page
  • Ctrl + Tab - switches to the next tab
  • Ctrl + Shift + Tab - switches to the previous tab
  • Ctrl + L - focuses the address bar
  • Ctrl + D - bookmarks the current page
  • Ctrl + J - opens the downloads page
  • Ctrl + R - refreshes the current page
